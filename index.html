JARVIS Mission Control Dashboard

Problem

Ten AI agents were running across 37 active automation workflows, but their state lived in three unconnected places: the automation platform, a Postgres database, and a Telegram chat. Answering "which agents are live, what is assigned, and what has this cost" meant opening three tools and reconciling them by hand.

What I built

A custom Obsidian plugin in TypeScript that puts the whole operation in one sidebar: agent roster with live status, task assignment straight to any agent, a 30-day revenue and spend overview, and one-click buttons that fire automation workflows. Each panel loads independently, so one failing data source degrades a single card instead of blanking the dashboard. It authenticates with a purpose-built least-privilege database role — read on three tables, write on one, deletes refused at the database — rather than the all-access key this kind of tool usually ships with.

n8n Automation Pipeline

Problem

Sourcing qualified trucking-carrier leads meant querying a federal registry by hand, stripping out carriers that did not fit, checking each one against records already contacted, and writing an individual pitch. It was several hours of repetitive work for a list that went stale within days.

What I built

A 12-stage n8n pipeline that runs unattended every morning: it queries the federal carrier registry, filters to the target profile, scores each carrier for fit with an AI model and drafts a tailored opening line, removes anyone already in the database, writes the result to Postgres, and posts a digest to Telegram. Full execution tracing is wired in, so a bad run is visible rather than silent.

Measurable result

12,845 qualified leads generated across 96 days of unattended operation — 97% with a phone number, 99% with an email. Roughly 15 new scored leads land every morning with zero manual steps, and every run in the retained execution window completed successfully.
